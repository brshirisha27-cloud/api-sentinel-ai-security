Machine Learning Dual-Engine
  • Model 1: Random Forest Classifier — 100 decision trees classifying requests into Normal (0), Suspicious (1), and Potential Attack (2) across 8 behavioral metrics.
  • Model 2: Isolation Forest — Unsupervised anomaly detection isolating out-of-distribution traffic vectors to discover zero-day attacks.
  • Composite Risk Scoring — Combines classification probabilities, multivariate outlier distance, and deterministic heuristics into a transparent 0–100 risk score.
How to Run Locally
git clone https://github.com/brshirisha27-cloud/api-sentinel-ai-security.git
cd api-sentinel-ai-security
pip install -r requirements.txt
python app.py
Runs locally on http://127.0.0.1:5000 with a persistent SQLite database and interactive SOC dashboard.
